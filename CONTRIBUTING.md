# Contributing to ARS

Thanks for helping build a more coherent realism experience for Farming Simulator 25.

ARS is under active development. Focused bug reports, compatibility investigations, documentation fixes and small, reviewable pull requests are welcome.

## Before opening an issue

Search existing [Issues](https://github.com/KeilerHirsch/FS25_Advanced_RealmsSuite/issues) and [Discussions](https://github.com/KeilerHirsch/FS25_Advanced_RealmsSuite/discussions). For bugs, share the ARS and FS25 versions, affected vehicle, other installed mods, game mode, reproduction steps, expected and actual behavior, and a **redacted** relevant log excerpt. Use a copied test save, not your only save.

## Before opening a pull request

- Describe the player-facing behavior and the reason for the change.
- Keep changes focused and avoid unrelated formatting or architecture churn.
- Verify available Lua/XML checks and name untested paths explicitly.
- For changes affecting vehicles or service state, consider persistence and multiplayer authority.
- Identify external material and its actual licence; never introduce source code or assets from other projects without the rights needed for redistribution.
- Do not include credentials, personal data, private server details or game saves.
- Document known limitations and report what was actually tested.

# Security policy

ARS is an in-development Farming Simulator 25 mod, **not** a security-hardened product.

## Reporting

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/KeilerHirsch/FS25_Advanced_RealismSuite/security/advisories/new).

Do not publish exploit details, secrets, private saves, credentials or personal information in public Issues or Discussions. For ordinary gameplay problems, use the [bug report template](https://github.com/KeilerHirsch/FS25_Advanced_RealismSuite/issues/new/choose) with sanitized logs.

Security advisories, responses and fixes are handled on a best-effort basis. No response-time guarantee or certification is claimed.
